# Profile Card — HNG 13 Stage 0

This project is a responsive **Profile Card** built using **HTML, CSS, and Vanilla JavaScript**, created as part of the **HNG 13 Internship Stage 0 Task**.

---

## 🌐 Live Demo
🔗Live Demo: [View Live on GitHub Pages](https://yiinkka.github.io/Profile-Card-HNG-13-Stage-0/)
🔗Github Repo: (https://github.com/Yiinkka/Profile-Card-HNG-13-Stage-0)


---

## 📁 Features
- User name, bio, avatar, and time (milliseconds)  
- Social media links with hover/focus animation  
- List of hobbies and dislikes  
- Dynamic time updating with JavaScript  
- Glassmorphism design + green ambient glow
